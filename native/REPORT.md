- Fix (card and kerr_closed.cpp Ipm): Pi = F + n J, J = s^3/3 R_J (its own term, no subtraction), r43 / r_{+4} + 1 = r_{+3} / r_{+4}: I = -(pref / r_{+4}) (F + r43 r41 / (r_{+4} r31) J), no division by r_{+3}.
