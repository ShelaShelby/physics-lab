- **Atom Controls panel, new sections** after View, in this order, each folding, each shown when the old panel showed its rows (`atom_panel.cpp` rules, copied): **Orbital** (orbital 1s…4f and its orientation in the cloud views, not the chart; Energy level n in the Orbit view; the energy note), **Cloud** (style, density, superposition with second orbital / orientation / mix / beat speed and its note, Slice cut direction and position; whenever the view is not Orbit, as the old panel), **Orbit** (Orbit style), **Scale and motion** (Spin in Cloud 3D, Scale, Zoom, Orbit-view Playback speed; not on the chart), **Nucleus** (quark style and nucleon detail from zoom 4, nucleon edge from zoom 3), **Chart** (tilt, height means, reset, the landscape note).

The old rows' choices and long notes now live in ONE table (`ui::atomChoices`, `ui::atomNote`, `ui::atomSplitLabel`, atom_panel.h) used by both panels; the old panel's output is unchanged (its strings moved, not edited). Choices are segmented buttons packed into rows that fit (5c.1 header, 14 px floor, solid panel and hover rules apply: same widgets).
- **Fact line:** wraps to at most two lines (`factLineRect(..., textH)`), "…" only when two are too short; a click still opens the whole fact. It is now shown in the **Atom Lab** too (it was Orbit-only, waiting for the Atom bottom left to be arranged): in the New UI the Atom picture's scale bar and decay lines sit above the toolbar row and the fact line (`AtomLab::insetBottomLeft`, 0 in the old UI).
- **Benchmark header:** new line `New UI: On` / `New UI: Off`.
- For the checks only (no pixels): `PL_FACT_LONGEST=1` shows the longest fact; script verb `astate` prints every Atom setting; the old rows note their buttons as `old.<key>=<value>` (their labels "On", "2p"… repeat); a segmented button can note each part by name.
