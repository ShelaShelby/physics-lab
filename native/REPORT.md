## Finding 1: the 90 % outline belongs to the state on screen
- Cause: `atom_view.cpp` took `fo = lab.fullOrb()` (the real orbital the Orientation falls back to: for m = ±1.. that is pz, dz², fz³) and used it for **every** outline call. I checked all call sites: there are four uses of that one `fo` — the slice contour (`outlineSlice`, line 346, plus the cut offset's `orbitals()[fo].n`), the side-view shadow (`outlineOf(fo).side`), the 3D wireframe (`outlineOf(fo).wire`), and the cache key `olOrb_`. All now follow the one variable, which is `lab.outlineStateId()` (= `stateId()`: a complex state's own id), and `orbitals()[stateOrbital(fo)]` for the n. A real orbital gives the same answer as before (`stateId()` = `fullOrb()`), so nothing changes for p, d, f real orientations.
- Test one level down (`testOutlineIsTheState`, 3 checks): for all 20 complex states the outline the view asks for is that state's id, not the fallback's (the fallback has the same n and l and is real); every complex state is zero on the z axis and its fallback is not; and the 90 % shape (radius, side-view width, side-view height) differs from the fallback's by **at least 0.187** (4f m = +1), margin **0.10** (about half the smallest measured difference). Before the fix the difference was 0 in 20 of 20 states.
- **The drawing itself was not seen** (no GPU, no Windows, no screen here): only what it asks for is tested. OWNER-TODO has the check.

## Finding 2: superposition norm
**Choice: normalise** (not refuse). Why: the maths is exact and needs no new physics. For ψ = aA + bB e^(−iθ) with A, B normalised, ∫|ψ|² = a² + b² + 2ab Re(⟨A|B⟩ e^(−iθ)); it is 1 only if ⟨A|B⟩ = 0. `overlapAB(A, B)` (new, atom_core) is the standard inner product: 0 for different n or l (orthogonal radial parts or spherical harmonics), and within one shell the overlap of the normalised angular parts (16 × 32 Gauss–Legendre points, exact for the degrees used; |value| < 1e-9 is rounding and returned as exactly 0). Overlapping pairs are only pairs of one shell (same n, l): the same state twice, or a real orbital with an m state (|⟨2px|2p m=+1⟩| = 1/√2). Refusing them would take away legitimate pairs, and a clear message does not make a wrong density right.
- `psiSuper` divides by √(superNorm2) **only when the pair overlaps**; for orthogonal pairs (all the others) the code path and every number are exactly the old ones, so no saved reference, dot hash or other test moved.
- Overlapping pairs always share one energy (same n), so the state is **static** (no beats). Their dots now come from the renormalised density itself (`overlap_` in `walkSuper`: the walker's target is |aA + bB|²), and **every dot is shown** (no 50 %–100 % thinning); a change of Mix refills the cloud (like a new orbital), because for these pairs Mix changes the shape, not a time dependence. Orthogonal pairs are unchanged (mixture sampled, exact thinning).
- **What Mix now means:** orthogonal pair: unchanged, a² and b² are exactly the probabilities. Overlapping pair: the percentages are the amplitudes of the mix, which is renormalised (the same state twice is that state, whatever the mix). The readout no longer prints "(50 % / 50 %)" then: it says "(amplitudes 50 % / 50 %; the states overlap by 71 %, so the mixture is renormalised)"; the beat line adds "one fixed state"; the Superposition note in the panel says it too.
- Tests (`testSuperNorm`, `testOverlapDots`, `testSuperReadout`, 10 checks): the integral of |ψ|² over all space, 18 pairs (same state twice, 1s twice, 2px + 2p m=+1, 2py + m=−1, 3dxz + m=+1, 3dx²−y² + m=+2, 4fxz² + m=+1, 3d m=+2 twice, and 10 orthogonal pairs incl. m=+1/−1, 1s+2p, 2s+2p, 4pz+4fz³, different n), at mix 0, 50, 100 % and two phases. **Before: largest |norm − 1| = 1.00009** (1s twice, mix 50: the integral was 2). **After: 6.62289e-4**, which is the midpoint quadrature's own error on an orthogonal pair (4pz + 4fz³; the overlapping pairs reach 1.19e-4); guard **6.69e-4** (measured + 1 %). The overlaps themselves from the maths (1; 1/√2 twice; exact 0 for five orthogonal pairs). Dots, 2px + 2p m=+1, 8 seeded labs per mix: the mean x², y², z² of the dots against the integrals of the lab's own ψ: before 0.944 off, after **0.05844**, guard **0.0591**; all dots shown. Readout: orthogonal pairs keep "(50 % / 50 %)", overlapping ones do not.
