All three: flat (no shine, no halo, solid), hairline border 8 % of the text colour, radii 12 or 10 (cards) / 8 (controls and hover pills), icon stroke 0.95 x = about 1.5 px at 1280x800, face 5 % towards the text colour, hover = face + 6 % towards the accent, padding 16.

- **M2 (Inter, blue pill):** bg #0b0b0c, card #111113, text #ededf0, muted #9797a0, accent #7aa8ff, selected fill #2563eb with white text (5.17:1 by my hand calculation, also in the test), line #26262b, card radius 10.
- **M3 (IBM Plex Sans):** exactly M1's tokens, only the font differs (so the owner compares typefaces).
- **Code changes besides tokens** (all guarded by "a look is on", so the default path is the old code): font loading (`ui/fonts.cpp`: families `m_inter`, `m_plex`, loaded only when `PL_LOOK` asks; today's font merged behind as fallback; `look.cpp` picks it), a selected row = ONE solid pill with regular weight and its text colour, section headers of the Controls panel muted and regular, icon buttons muted at rest / bright on hover, check boxes radius 4, slider track 3 px, and one wrap fix (below).
- **Found while testing:** the Atom card's decay line ends in " …" (more decay modes, `atom_core.cpp:836`). In M3's wider font the "…" wrapped alone on a third line and `ui5h_fit` rightly flagged it. Fixed in the look (a lone "…" takes the word before it to the new line, look only), not in the test.
- **Fonts** (from the Ubuntu 24.04 packages, files and licences read in this session): **Inter**, package `fonts-inter 4.0+ds-1`, `Inter-Regular.otf` + `Inter-SemiBold.otf` (CFF outlines; Dear ImGui 1.92.9b's stb_truetype reads them, the app draws them); copyright file: "2016-2023 The Inter Project Authors", licence **OFL-1.1** (the file also names Apache-2.0 for build scripts; not used), upstream github.com/rsms/inter. **IBM Plex Sans**, package `fonts-ibm-plex 6.1.1-1`, `IBMPlexSans-Regular.ttf` + `-SemiBold.ttf`; "2017-2018 IBM Corporation", **OFL-1.1**, Reserved Font Name "Plex" (the files are unmodified, so allowed), upstream github.com/IBM/plex. Bold = SemiBold. No italic file: italic text is drawn upright. Licence texts copied unchanged: `assets/fonts/OFL-Inter.txt`, `OFL-IBMPlexSans.txt`. About, "Where the facts come from", has a new Fonts entry.
- **Packaging:** the fonts are built into the .exe (`cmake/embed_fonts.cmake`, now also `*.otf`), so no file must sit next to it.
