## B. The helper (app/gpu_helper.cpp, vk_helper.cpp)
- Time limit per helper: 30 s (a design choice: about 100 x the slowest helper seen, the lines' 320 ms in the owner's log; said in the code). At the limit: TerminateProcess/kill, log "the helper hung making <step> (no answer after 30 s)", the guard's record as helperDied (off, "hung"), a variant's line "variant <name>: hung making it (no answer after 30 s)", next helper. Now the code is a long long; "ended without a result (exit code N)" is logged when no "done" line came.
